02

发行与证明

YDA 发行公式的零知识验证

让每一次 YDA 发行都能被证明符合既定的发行规则，同时不公开不应公开的数据。

方向说明

YDA 的发行数量由平台内部市场的成交数据，按既定的发行公式计算。我们希望任何人都能核对：某次发行是否按照当时的规则和已记录的数据计算，供应总量是否守恒，而不必相信平台单方面给出的数字。证明系统、电路设计和开发框架由候选人提出。

01 / 系统范围

当前范围与后续方向

CURRENT

当前范围

  1. 每次发行的数量按当时生效的公式计算
  2. 证明使用的成交数据与已存证的记录一致
  3. 供应总量守恒，新增发行可以追溯
  4. 每次发行及其证明对应明确的规则版本
  5. 第三方可以使用公开工具独立验证

NEXT

后续方向

  1. 在不公开逐笔交易明细、个人身份或内部参数的前提下完成验证
  2. 发行规则调整后，历史发行仍可按当时的规则版本验证
  3. 迁移到 YLand 自有链后，在链上验证并留存证明（见方向 01）
  4. 证明生成的时间和成本随交易量增长保持可控

重要说明：发行公式的具体内容和参数不在本页公开，方案需要能够适应规则和参数的调整。零知识证明只能说明计算符合规则，不能证明输入数据本身真实；输入是否可信，取决于交易记录的存证与核验。

02 / 主要业务流程

方案需要支撑的流程

  • 发行计算
  • 证明生成
  • 证明验证
  • 供应核对
  • 规则版本更新

核验对象：外部参与者应能使用公开工具，核对某次发行的证明、对应的规则版本和链上记录，不必依赖 YLAND 单方面给出的结论。

03 / 方案应说明

让我们能够比较不同候选方案

  • 你对 YDA 发行验证目标的理解
  • 哪些数据公开、哪些保密，以及划分理由
  • 推荐的证明系统、关键假设与选择理由
  • 复杂数值计算如何在证明中可靠表达
  • 最小版本、阶段计划、预计时间与成本
  • 安全、可信设置、性能与运维风险
