03

钱包与协作

YDA 数字价值与结算

围绕 YDA 的钱包、接口、支付选择与商户结算，建设平台内部数字价值协作所需的基础能力。

方向说明

这个方向关注 YDA 如何被安全记录、使用和结算，而不是订单簿如何撮合。我们说明必要的业务能力与当前范围，不指定钱包、账务、支付或结算的技术实现；候选人需要提出符合当前阶段和合规条件的方案。

01 / 系统范围

当前范围与后续方向

CURRENT

当前范围

  1. HKD 与 YDA 的可用余额和冻结余额
  2. 钱包记录、接口版本与开发者文档
  3. 商户主动开启的快捷兑换或结算能力
  4. 正常 HKD 支付流程与商户侧结算的隔离
  5. 失败、取消、退款和后备结算记录
  6. 交易成交后钱包余额与账务状态更新

NEXT

后续方向

  1. 完整 HKD 入金、划转、提现和银行结算
  2. 面向更多支付场景的通用支付与自动兑换
  3. 完整结账、退款和争议处理体系
  4. YDA 发行与供应管理机制

方向关系：YDA/HKD 委托与撮合属于交易系统；YDA 方向负责钱包和结算。发行、供应、内部汇率、银行及支付服务商方案尚未确定。

02 / 主要业务流程

方案需要支撑的流程

  • 商户快捷兑换结算
  • 后备结算
  • 失败、取消与退款
  • 外部接入

用户侧原则：快捷兑换只影响商户侧的结算、手续费和账务记录。用户端不展示 YDA、兑换汇率或兑换步骤，也不要求用户持有 YDA；已经买入 YDA 的用户可以自行选择开启使用 YDA 支付。

03 / 方案应说明

让我们能够比较不同候选方案

  • 你对目标、用户和业务重点的理解
  • 推荐方案、关键假设与选择理由
  • 成熟平台已经验证的技术或实践
  • 方案相较其他可行方案的优势
  • 最小版本、阶段计划、预计时间与成本
  • 安全、隐私、合规与运营风险
